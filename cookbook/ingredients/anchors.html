The anchor element (also known as a link or hyperlink) can be used to navigate the user to a different location on the current page, or to a different page entirely.

By default, anchor elements are inline elements, meaning they will appear "in line" with other text around them. So if we add four anchor elements right here: External Hyperlinks Internal Hyperlinks Jump Links Dummy Anchor They will all line up right next to each other, even though if you look in the code, you'll see they're on separate lines.

To use anchor elements, you will need to provide a hyperlink reference, or 'href', attribute. Depending on what you provide to the href attribute,

  • you can create anchors that navigate to other pages called external hyperlinks and internal links,
  • or you can also create anchors that navigate somewhere on the same page called jump links.

Because these concepts can get rather complex, we have split them up into their own Cookbook pages.
